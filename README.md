Welcome to the official open-source repository of the **HTML5 Gold of Egypt Slot Game Engine**. ## 🚀 Key Technical Features & Capabilities

* **100% Clean Open Source:** Built with clean, readable JavaScript and structured modules. No obfuscated code, no hidden backdoors, and no encrypted dependencies.
* **Core Phaser 3 Framework:** Leverages hardware-accelerated WebGL rendering with automatic fallback to Canvas, guaranteeing smooth 60 FPS performance across low-end mobile devices and high-end desktop rigs.
* **Modular Reskinning System:** Easily adapt the visual identity. The architecture separates game logic from assets, allowing developers to change backgrounds, symbol sprites, sound effects, and configuration parameters within minutes.
* **Cross-Platform Responsiveness:** Built-in auto-scaling layout manager that dynamically adjusts the 1920x1080p canvas to fit any screen aspect ratio (smartphones, tablets, laptops, ultra-wide monitors).
* **Advanced Slot Mechanics Built-In:**
  * Classic **5x3 Reel Matrix** configuration with customizable payline algorithms.
  * Native **Wild, Scatter, and Free Spin** trigger logic.
  * Integrated **Jackpot Engine** and multi-tier celebratory win screens (*Big Win, Huge Win, Mega Win*).
  * Comprehensive UI Suite featuring **9 Interactive Pop-Up Modals** (Settings, Dynamic Paytable, Paylines, Rules, Help, and Statistics).
  * Local browser data persistence (`localStorage`) for user session states, audio preferences, and balance tracking.
